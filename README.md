# Phish-Defender 🛡️

Un outil éducatif de défense contre le phishing (Blue Team), développé en Python. 
Il permet d'analyser des emails suspects, de détecter les faux domaines (typosquatting) et d'identifier les liens piégés.

## 🚀 Fonctionnalités
- 🌐 **Analyse de domaine** : Détecte les domaines qui ressemblent à de grandes marques (ex: `paypaI.com`).
- 🔗 **Analyse d'URL** : Repère les adresses IP, les raccourcisseurs de liens et les liens trompeurs.
- 📧 **Scoring d'email** : Analyse le contenu d'un email (.eml) et lui attribue un score de dangerosité (Faible, Moyen, Élevé).
- 🧪 **Tests unitaires** : Suite de tests pour vérifier la fiabilité des détections.

## ⚠️ Avertissement Légal (Educational Purpose Only)
**Cet outil est destiné à un usage éducatif et éthique uniquement.**
Il a été conçu pour aider les utilisateurs à se protéger contre les attaques de phishing. N'utilisez jamais cet outil pour faciliter des attaques.
